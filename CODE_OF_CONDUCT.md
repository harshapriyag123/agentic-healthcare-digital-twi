# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

We pledge to make participation harassment-free for everyone and to foster an open, welcoming, diverse, inclusive, and healthy community. Examples of unacceptable behavior include harassment, discrimination, sexualized attention, threats, trolling, publishing others' private information, or unsafe handling of healthcare/security data.

Project maintainers are responsible for clarifying and enforcing standards and may remove, edit, or reject contributions or participation that are inappropriate, threatening, harmful, or inconsistent with this Code. Report conduct concerns privately to the repository owner through GitHub. Maintainers will respect reporter privacy to the extent practical and apply the Contributor Covenant enforcement guidelines proportionately.

For the complete scope, standards, responsibilities, and enforcement ladder, follow the canonical Contributor Covenant text linked above. This Code applies in project spaces and when representing the project publicly.
