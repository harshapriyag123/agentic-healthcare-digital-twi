# Threat model

## Protected assets

- healthcare-service availability;
- digital-twin state integrity;
- telemetry provenance;
- agent recommendation integrity;
- aggregate infrastructure data.

## Modeled attacks

- ransomware-driven capacity loss;
- credential abuse;
- telemetry suppression and falsification;
- compromised infrastructure dependencies;
- adversarial compound events that coincide with environmental hazards.

## Trust boundaries

Recommendations never authorize treatment, triage or dispatch. Low telemetry integrity lowers confidence and can force quarantine/human-review behavior.
