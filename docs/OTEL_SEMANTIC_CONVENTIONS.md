# Proposed OpenTelemetry attributes

| Attribute | Meaning |
|---|---|
| `geotwin.simulation.id` | Reproducible simulation run identifier |
| `geotwin.scenario.name` | Scenario or experiment name |
| `healthcare.facility.id` | Synthetic/aggregate facility identifier |
| `healthcare.load.ratio` | Estimated demand divided by effective capacity |
| `geotwin.cyber.loss` | Fractional operational loss attributable to cyber disruption |
| `geotwin.hazard.pressure` | Fused environmental hazard pressure |
| `geotwin.disruption.probability` | Predicted facility disruption probability |
| `security.telemetry.integrity` | Estimated reliability of observed telemetry |
| `ai.decision.confidence` | Calibrated confidence of the recommendation |
| `ai.decision.human_review_required` | Whether an authorized reviewer must approve action |
