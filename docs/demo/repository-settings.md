# Recommended repository settings

Repository-host settings are not changed by files alone. After the public deployment is verified, set:

- Description: “Observable agentic geospatial digital twin for synthetic healthcare infrastructure resilience research.”
- Homepage: verified public frontend URL only.
- Topics: `digital-twin`, `agentic-ai`, `healthcare-infrastructure`, `geospatial`, `open-telemetry`, `signoz`, `trustworthy-ai`, `counterfactual-reasoning`, `crisis-management`, `synthetic-data`.
- Social preview: a sanitized 1280×640 composition with project name, command-center/GIS crop, synthetic-data label, and no tiny text/private URLs.
- Enable private vulnerability reporting, issue templates, branch protection/required CI, and dependency/security scanning as appropriate.

Do not add a deployment or publication badge until its target is public and verified.
