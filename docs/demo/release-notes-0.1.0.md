# GeoTwin Sentinel 0.1.0 — draft release notes

This first hackathon research release connects three synthetic compound-disruption scenarios to a geospatial healthcare infrastructure digital twin, Crisis Command Center, rule-based Agent Activity Console, Counterfactual Explorer, versioned Trust and Evidence Dashboard, and OpenTelemetry/SigNoz workflow.

It includes a FastAPI/React implementation, five-hospital synthetic catalog, GIS and accessible tables, process-local baseline comparison, evidence-linked human-review policy, non-root container, Render/Vercel reference deployment, CI, smoke tests, and judge/developer/research documentation.

Known limits: synthetic and simplified models only; no clinical/causal/security validation; no operational authority; process-local history; no authentication/rate limiter; external tile/telemetry/cloud dependencies; public demo, screenshots, video, and live SigNoz receipt require manual publication/verification. See [limitations](../research/limitations.md).
