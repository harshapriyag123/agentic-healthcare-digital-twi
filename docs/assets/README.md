# Documentation assets

`screenshots/` and `diagrams/` are reserved for reviewed publication assets. No screenshots or rendered diagrams are currently committed. Mermaid source diagrams live in the architecture Markdown so GitHub can render and review them.

Before adding an image, follow the filename, resolution, state, caption, and sensitive-data checklist in [`../demo/recording-shot-list.md`](../demo/recording-shot-list.md). Never add secrets, private dashboard URLs, personal browser content, real health data, local file paths, or a loading/error screen presented as a working demo.
